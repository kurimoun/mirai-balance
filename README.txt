・グラフの選択月に縦のガイド線を表示します。
・グラフの点のタップ判定を大きくし、iPhoneで押しやすくしました（見た目の点のサイズはそのままです）。

更新手順
1. PWAのデータ管理からJSONバックアップを保存する。
2. ZIPを展開し、その中のファイルをGitHub Desktopで開いた mirai-balance のリポジトリ直下に上書きする。
3. GitHub Desktopで Commit to main → Push origin。GitHub Actionsの公開成功を確認する。
4. iPhoneをオンラインで起動し、画面下部の Ver.0.3.9 を確認する。

注意: PWAのホーム画面アイコンやSafariのサイトデータは削除しないでください。iPhone実機動作は未検証です。
