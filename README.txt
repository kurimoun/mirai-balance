ミライ残高 PWA Ver.0.6.7
日付別残高の表示を改善しました。
・過去の日付はグレー表示し、「過去・参考推計」または「過去・未照合」と表示します。
・今日の日付は淡い緑色で強調し、「今日」と表示します。
・未来の日付は「予測」と表示します。
・実績登録との照合差額は「実績照合」と表示します。
・日末残高がマイナスの場合は赤字で表示します。
表示のみの変更で、残高計算・既存データ形式は変更していません。
ZIPの中身をGitHub Desktopのリポジトリ直下に上書きし、Commit to main → Push originを実行してください。
更新前にアプリ内のJSONバックアップを保存してください。GitHub Pagesへの反映後、アプリをオンラインで開き直してください。
