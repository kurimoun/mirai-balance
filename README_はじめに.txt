ミライ残高 PWA試用版 0.1

【重要】これは既存のReact Native iPhone版0.5.9.2をそのまま移したものではなく、旧Web版0.6.3をPWA化した試用版です。画面配置、カード追加・編集、祝日による翌営業日調整などに差があります。iPhone版を上書き・削除しないでください。

【使い方】
1. このフォルダの index.html, sw.js, manifest.webmanifest, icon画像を全部まとめてHTTPSサイトにアップロードします。
2. GitHub Pages等の静的ホスティングで公開します。必ずHTTPSのURLでアクセスしてください。個人の残高・給与をGitHubにアップロードしてはいけません。
3. iPhoneのSafariでHTTPSのURLを開き、共有 → ホーム画面に追加 → 追加します。
4. オンラインで一度開いたあと、機内モードで再起動してオフライン動作を確認します。
5. 「設定・データ」から以前のJSONを復元します。口座の基準日・残高、請求額を確認してから利用してください。

【注意】
- zipファイルをiPhoneで直接開くだけではPWAのオフライン機能は有効になりません。HTTPS配信が必要です。
- データはiPhoneのブラウザ保存領域に保存され、Expo Goのデータとは自動で同期されません。
- バックアップJSONは非公開で保管してください。公開GitHubリポジトリへ置かないでください。
- 旧Web版ベースのため、最新のReact Native版と見た目/一部機能が異なります。特にカード支払日の銀行休業日調整はありません。
- Safariのデータ削除やホーム画面からの削除などで記録が失われる可能性があります。定期的にJSONバックアップを保存してください。
